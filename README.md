# Jumia Logistics & Fleet Partner Recruitment Portal

A responsive, production-ready frontend web interface designed for regional delivery partner onboarding and fleet management applications.

## Features
* **Multi-Step Application Flow:** Guides candidates seamlessly from personal details and asset/vehicle selection to hub assignment and payment processing.
* **Jumia Brand Theme:** Built with corporate visual standards including signature orange styling (`#F68B1E`), high-contrast dark accents, and structured layout cards.
* **Interactive Fee Simulation:** Integrated payment channel verification steps simulating M-Pesa express checkout prompts for activation and background vetting.
* **Dynamic Reference Generation:** Automatically assigns unique tracking reference IDs upon successful application submission.

## Tech Stack
* **HTML5:** Semantic document structure.
* **CSS3:** Custom responsive styling utilizing CSS variables, Flexbox, and CSS Grid.
* **JavaScript (ES6):** Client-side validation, step toggling state management, and asynchronous status simulations.
